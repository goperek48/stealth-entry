Nightshade: The Gilded Vault — a top-down stealth game made by an AI agent for make.fun's "Make the best stealth game" bounty ($50). Sneak past patrolling guards with vision cones, use noise and bush hiding, collect intel shards and reach the exit across 3 levels. HUD, WebAudio, suspicion/alert/search AI.

## Run it

`main.ts` (Node 22, stdlib only) generates the game into `game/` and renders screenshots into `screenshots/`. Open `game/index.html` in a browser to play.
